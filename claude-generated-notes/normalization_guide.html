Normalization Layers

BatchNorm · LayerNorm · InstanceNorm · GroupNorm · RMSNorm — what they do, why they exist, where to use them.
Written in simplified technical English (about 80% ASD-STE100 style: short sentences, simple words, one idea per sentence).

1. The big idea

Deep networks train badly when the size of the activations changes from layer to layer. Large values make gradients unstable. Small values make them vanish.

A normalization layer fixes this. It does three steps:

  1. Find the mean and variance of a group of numbers.
  2. Subtract the mean and divide by the standard deviation.
  3. Apply a learned scale (γ) and shift (β), so the network can undo the change if needed.

The only difference between the norms is: which numbers are put in the same group.

General form: y = γ · (x − μ) / √(σ² + ε) + β μ = mean of the group σ² = variance of the group ε = small number (1e-5) to avoid division by zero

2. Diagram: which numbers share statistics?

Take a tensor of shape (N, C, H, W): N samples, C channels, H×W pixels. Each small square below is one (sample, channel) pair. Squares with the same color share one mean and one variance.

Rows = samples (N=4). Columns = channels (C=6). Each square hides the H×W pixels. For a Transformer, read "channel" as "feature" and "sample" as "token".

3. Each norm in detail

BatchNorm (Ioffe & Szegedy, 2015)

Normalizes over the batch and pixels (N, H, W), one set of statistics per channel.
μ_c = (1 / NHW) · Σ_{n,h,w} x_{n,c,h,w} σ²_c = (1 / NHW) · Σ_{n,h,w} (x_{n,c,h,w} − μ_c)² y = γ_c · (x − μ_c) / √(σ²_c + ε) + β_c Inference: μ, σ² come from running averages saved during training: running = (1 − m) · running + m · batch_stat

Need: Training of deep CNNs was slow and needed very small learning rates. BatchNorm keeps activations stable, allows large learning rates, and acts as a mild regularizer (the batch noise).

Limits: Needs a large batch (≥ 16–32 per device). Training and inference behave differently. Does not fit variable-length sequences well.

Used in: ResNet, EfficientNet, most image classifiers.

LayerNorm (Ba et al., 2016)

Normalizes over all features of one sample (or one token). No batch dependence.
μ = (1 / D) · Σ_i x_i σ² = (1 / D) · Σ_i (x_i − μ)² y_i = γ_i · (x_i − μ) / √(σ² + ε) + β_i D = feature size

Need: BatchNorm fails in RNNs (each time step has different statistics) and with batch size 1. LayerNorm gives the same result in training and inference.

Used in: Transformers (BERT, GPT-2, ViT), LSTM/GRU variants.

InstanceNorm (Ulyanov et al., 2016)

Normalizes over the pixels (H, W) of one channel of one sample.
μ_{n,c} = (1 / HW) · Σ_{h,w} x_{n,c,h,w} σ²_{n,c} = (1 / HW) · Σ_{h,w} (x_{n,c,h,w} − μ_{n,c})² y = γ_c · (x − μ_{n,c}) / √(σ²_{n,c} + ε) + β_c

Need: In style transfer, the mean and variance of each channel carry the "style" (contrast, color). InstanceNorm removes the style of the input image, so a new style can be added. (AdaIN replaces γ and β with values from a style image.)

Used in: Style transfer, CycleGAN, StyleGAN-type generators.

GroupNorm (Wu & He, 2018)

Normalizes over a group of channels (C/G channels) and all pixels, per sample.
Split C channels into G groups. Group g has C/G channels. μ_{n,g} = (1 / (C/G · HW)) · Σ_{c ∈ g, h, w} x_{n,c,h,w} σ²_{n,g} = (1 / (C/G · HW)) · Σ_{c ∈ g, h, w} (x − μ_{n,g})² y = γ_c · (x − μ_{n,g}) / √(σ²_{n,g} + ε) + β_c Special cases: G = 1 → LayerNorm over (C,H,W); G = C → InstanceNorm

Need: Detection and segmentation use large images, so the batch is often 1–2. BatchNorm is poor there. GroupNorm does not depend on batch size.

Used in: Mask R-CNN, video models, diffusion U-Nets (Stable Diffusion uses 32 groups).

RMSNorm (Zhang & Sennrich, 2019)

Normalizes over the same axis as LayerNorm, but does not subtract the mean and has no β.
RMS(x) = √( (1 / D) · Σ_i x_i² + ε ) y_i = γ_i · x_i / RMS(x)

Need: The authors found that the scaling (not the centering) gives most of the benefit of LayerNorm. Skipping the mean saves compute and memory, about 7–60% faster in the norm layer, with similar quality. This matters for large language models.

Used in: LLaMA, Mistral, Gemma, T5 (a variant), and most modern LLMs.

4. Code from scratch (PyTorch)

Only basic tensor operations are used. No nn.BatchNorm or similar.

import torch
import torch.nn as nn


class BatchNorm2d(nn.Module):
    def __init__(self, C, eps=1e-5, momentum=0.1):
        super().__init__()
        self.eps, self.m = eps, momentum
        self.gamma = nn.Parameter(torch.ones(1, C, 1, 1))
        self.beta = nn.Parameter(torch.zeros(1, C, 1, 1))
        self.register_buffer("run_mean", torch.zeros(1, C, 1, 1))
        self.register_buffer("run_var", torch.ones(1, C, 1, 1))

    def forward(self, x):                      # x: (N, C, H, W)
        if self.training:
            mean = x.mean(dim=(0, 2, 3), keepdim=True)
            var = x.var(dim=(0, 2, 3), unbiased=False, keepdim=True)
            with torch.no_grad():              # update running statistics
                self.run_mean.mul_(1 - self.m).add_(self.m * mean)
                self.run_var.mul_(1 - self.m).add_(self.m * var)
        else:
            mean, var = self.run_mean, self.run_var
        x_hat = (x - mean) / torch.sqrt(var + self.eps)
        return self.gamma * x_hat + self.beta


class LayerNorm(nn.Module):
    def __init__(self, D, eps=1e-5):
        super().__init__()
        self.eps = eps
        self.gamma = nn.Parameter(torch.ones(D))
        self.beta = nn.Parameter(torch.zeros(D))

    def forward(self, x):                      # x: (..., D)
        mean = x.mean(dim=-1, keepdim=True)
        var = x.var(dim=-1, unbiased=False, keepdim=True)
        return self.gamma * (x - mean) / torch.sqrt(var + self.eps) + self.beta


class InstanceNorm2d(nn.Module):
    def __init__(self, C, eps=1e-5):
        super().__init__()
        self.eps = eps
        self.gamma = nn.Parameter(torch.ones(1, C, 1, 1))
        self.beta = nn.Parameter(torch.zeros(1, C, 1, 1))

    def forward(self, x):                      # x: (N, C, H, W)
        mean = x.mean(dim=(2, 3), keepdim=True)
        var = x.var(dim=(2, 3), unbiased=False, keepdim=True)
        return self.gamma * (x - mean) / torch.sqrt(var + self.eps) + self.beta


class GroupNorm(nn.Module):
    def __init__(self, G, C, eps=1e-5):
        super().__init__()
        assert C % G == 0, "C must be divisible by G"
        self.G, self.eps = G, eps
        self.gamma = nn.Parameter(torch.ones(1, C, 1, 1))
        self.beta = nn.Parameter(torch.zeros(1, C, 1, 1))

    def forward(self, x):                      # x: (N, C, H, W)
        N, C, H, W = x.shape
        xg = x.view(N, self.G, -1)             # one row per (sample, group)
        mean = xg.mean(dim=-1, keepdim=True)
        var = xg.var(dim=-1, unbiased=False, keepdim=True)
        x_hat = ((xg - mean) / torch.sqrt(var + self.eps)).view(N, C, H, W)
        return self.gamma * x_hat + self.beta


class RMSNorm(nn.Module):
    def __init__(self, D, eps=1e-6):
        super().__init__()
        self.eps = eps
        self.gamma = nn.Parameter(torch.ones(D))   # no beta, no mean

    def forward(self, x):                      # x: (..., D)
        rms = torch.sqrt(x.pow(2).mean(dim=-1, keepdim=True) + self.eps)
        return self.gamma * x / rms


# Quick check against the PyTorch versions
if __name__ == "__main__":
    x = torch.randn(4, 6, 8, 8)
    print(torch.allclose(BatchNorm2d(6)(x), nn.BatchNorm2d(6)(x), atol=1e-5))
    print(torch.allclose(GroupNorm(2, 6)(x), nn.GroupNorm(2, 6)(x), atol=1e-5))
    print(torch.allclose(InstanceNorm2d(6)(x), nn.InstanceNorm2d(6)(x), atol=1e-5))
    t = torch.randn(2, 10, 32)
    print(torch.allclose(LayerNorm(32)(t), nn.LayerNorm(32)(t), atol=1e-5))

5. Use in different architectures

ArchitectureCommon choiceHow it is used and why
CNN (ResNet, VGG-BN)BatchNorm; GroupNorm if the batch is smallPlaced after each convolution, before the activation: Conv → BN → ReLU. Large image batches give good statistics. For detection or segmentation (batch 1–2), use GroupNorm.
Transformer (BERT, GPT, ViT)LayerNorm; RMSNorm in modern LLMsApplied to the token vector (size D). The original Transformer used Post-LN (norm after the residual add). Most new models use Pre-LN (norm before attention and MLP), which trains more stably. LLaMA-style models use Pre-RMSNorm. BatchNorm is a poor fit: sequence lengths and padding change the statistics.
LSTM / GRULayerNormApplied to the gate pre-activations at each time step (e.g. the input-to-hidden and hidden-to-hidden sums), and sometimes to the cell state. It does not depend on the batch or on the sequence length. BatchNorm needs separate statistics for each time step, so it is hard to use.
DNN / MLPBatchNorm or LayerNormLinear → Norm → Activation. BatchNorm helps with large batches. LayerNorm is better for small batches, tabular data, and reinforcement learning.
Generative models (GAN, style transfer, diffusion)*InstanceNorm, GroupNormInstanceNorm in style transfer and CycleGAN generators (removes per-image style). BatchNorm in DCGAN generators. GroupNorm in diffusion U-Nets. Critics in WGAN-GP avoid BatchNorm (it mixes samples) and use LayerNorm or none.
